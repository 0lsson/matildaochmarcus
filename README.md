# matildaochmarcus.se

Bröllopshemsida för Matilda & Marcus, 4 september 2027.

- `index.html` – hela sidan (text, stil och lite JavaScript)
- `assets/` – blommor från save the date-kortet, favicon och delningsbild
- `CNAME` – kopplar sidan till domänen matildaochmarcus.se

## Lägga till bilder
Lägg bilder i en mapp `bilder/` och byt ut en tom ruta under "Om oss" mot:

```html
<figure class="photo" style="margin:0"><img src="bilder/vi-1.jpg" alt="Matilda och Marcus"></figure>
```
